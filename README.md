# 策衡 EquiStrat 官网

策衡 EquiStrat 医疗 AI 产业咨询公司官网，围绕产业达人矩阵、品牌全域宣发、产业咨询与企业 AI 定制服务，呈现公司能力、产业资源、合规机制与商务合作入口。

## 网站内容

- 医疗 AI 产业品牌首屏与核心数据
- 三大核心服务
- 六大垂直赛道交互筛选
- 院士、企业、创投与国际政企资源矩阵
- 医疗传播合规审核流程
- 商务咨询留资表单
- 桌面端与移动端响应式布局

## 本地运行

需要 Node.js `>=22.13.0`。

```bash
npm install
npm run dev
```

打开 [http://localhost:3000](http://localhost:3000)。

## 构建

```bash
npm run build
```

项目基于 React、vinext、Vite 与 Tailwind CSS 构建。
